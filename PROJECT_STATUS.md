## 🛠 Engineering Focus: Hardware Acceleration

The current engineering priority is the transition from stable CPU-based inference to hardware-accelerated execution via CUDA PTX and CUTLASS. While the backend abstraction and dispatch layers are architecturally complete, the primary work resides in implementing the kernel launch primitives for the WGMMA and TCGEN05 paths.

### 🎯 Current Objectives
1.  **Kernel Launch Implementation:** Moving from the `// TODO` placeholder in `attention.rs` to a functional `self.function.launch()` call.
2.  **Verification:** Establishing a byte-exact comparison between the CPU fallback and the new GPU-accelerated path using the `pesti-conformance` suite.
3.  **Performance Benchmarking:** Measuring the throughput delta (tokens/sec) between the pure-Rust CPU path and the CUDA-oxide/Mistral.rs backends.
